# التحكم بالجهاز عن بُعد 🖥️📱

نظام للتحكم بجهازك (**جهازك أنت**) من الجوال: إيقاف تشغيل، إعادة تشغيل، سكون، قفل، تسجيل خروج، وتشغيل (Wake-on-LAN).

- **الواجهة** صفحة ويب على **Vercel** تفتحها من متصفح الجوال.
- **الكود** على **GitHub** ويُنشر تلقائياً على Vercel عند كل تحديث.
- **برنامج صغير (Agent)** يعمل على جهازك ويستقبل الأوامر وينفّذها.
- كل شيء **محمي**: كلمة سر للواجهة + رمز سري للجهاز. لا أحد يتحكم إلا أنت.

```
   📱 جوالك                ☁️ Vercel + KV              💻 جهازك
 ┌──────────┐   أمر    ┌──────────────────┐   يسأل    ┌──────────────┐
 │ صفحة ويب │ ───────▶ │ API + قائمة أوامر │ ◀──────── │  Agent (بايثون) │
 │          │ ◀─────── │   (حالة الاتصال)   │ ───────▶ │  ينفّذ الأمر   │
 └──────────┘  النتيجة  └──────────────────┘   النتيجة  └──────────────┘
```

> **كيف يعمل خلف الراوتر بدون فتح منافذ؟** جهازك هو من *يسأل* السيرفر باستمرار (polling)،
> فلا حاجة لعنوان IP ثابت ولا فتح بورتات ولا إعدادات راوتر. آمن وبسيط.

---

## ما تحتاجه

1. حساب **GitHub** (مجاني).
2. حساب **Vercel** (مجاني) — سجّل الدخول فيه عن طريق GitHub.
3. **Python 3.8+** مثبّت على جهازك ([python.org](https://www.python.org/downloads/) — على ويندوز فعّل خيار *Add Python to PATH*).

---

## الخطوة ١ — ارفع الكود على GitHub

أنشئ مستودعاً جديداً (مثلاً `remote-pc-control`) وارفع هذه الملفات فيه. من داخل المجلد:

```bash
git init
git add .
git commit -m "Remote PC control"
git branch -M main
git remote add origin https://github.com/USERNAME/remote-pc-control.git
git push -u origin main
```

> ملف `.gitignore` يمنع رفع أسرارك (`config.json` و`.env`) تلقائياً. ممتاز.

---

## الخطوة ٢ — انشر على Vercel

1. ادخل [vercel.com](https://vercel.com) → **Add New… → Project**.
2. اختر مستودع GitHub الذي رفعته → **Import**.
3. لا تحتاج تغيير أي إعداد بناء (المشروع بدون framework) → **Deploy**.
4. بعد النشر بتحصل رابطاً مثل: `https://remote-pc-control-xxxx.vercel.app`

---

## الخطوة ٣ — أضف قاعدة التخزين (Vercel KV)

يحتاج النظام مكاناً صغيراً يخزّن فيه الأوامر بين الجوال والجهاز.

1. داخل مشروعك في Vercel → تبويب **Storage** → **Create Database** → اختر **KV** (Upstash Redis) → الخطة المجانية.
2. اربطه بالمشروع (**Connect to Project**).
3. سيضيف Vercel تلقائياً المتغيّرين `KV_REST_API_URL` و `KV_REST_API_TOKEN`. ما تحتاج تكتبهما بنفسك.

---

## الخطوة ٤ — اضبط كلمتي السر

في Vercel → **Settings → Environment Variables**، أضف:

| الاسم | القيمة |
|------|--------|
| `UI_PASSWORD` | كلمة سر تكتبها في صفحة الجوال (اختر شيئاً قوياً) |
| `AGENT_TOKEN` | رمز سري طويل عشوائي (للجهاز) |

ولّد رمزاً عشوائياً قوياً بهذا الأمر:

```bash
python -c "import secrets; print(secrets.token_urlsafe(32))"
```

> بعد إضافة المتغيّرات، اعمل **Redeploy** للمشروع (تبويب Deployments → آخر نشر → Redeploy) حتى تُطبَّق.

---

## الخطوة ٥ — شغّل الـ Agent على جهازك

1. في مجلد `agent/`: انسخ `config.example.json` إلى **`config.json`**.
2. املأه:

```json
{
  "server_url": "https://اسم-مشروعك.vercel.app",
  "agent_token": "نفس قيمة AGENT_TOKEN التي وضعتها في Vercel",
  "poll_interval": 2,
  "heartbeat_interval": 15,
  "wol_mac": "AA:BB:CC:DD:EE:FF",
  "wol_broadcast": "255.255.255.255"
}
```

3. شغّله:

```bash
cd agent
python agent.py
```

لو ظهر `في انتظار الأوامر…` فأنت جاهز ✅ (وبيظهر «متصل» في الجوال).

---

## الخطوة ٦ — تحكّم من الجوال

افتح رابط Vercel في متصفح جوالك → اكتب `UI_PASSWORD` → تظهر الأزرار.
للراحة: من قائمة المتصفح اختر **«إضافة إلى الشاشة الرئيسية»** فيصير مثل تطبيق.

---

## التشغيل التلقائي (ليبقى الـ Agent دائم العمل)

**ويندوز (الأفضل):** افتح **Task Scheduler** → *Create Task*:
- Trigger: *At log on*.
- Action: *Start a program* → البرنامج: `wscript.exe`، والوسيطة: مسار `run_agent_hidden.vbs` (يشغّله بالخلفية بدون نافذة).
- في *Settings* فعّل *Restart the task if it fails*.

(أو ببساطة ضع اختصاراً لـ `run_agent.bat` داخل مجلد Startup: زر ويندوز+R ثم `shell:startup`.)

**لينكس:** عدّل واستخدم `rpc-agent.service` (الشرح داخل الملف).

**ماك:** شغّل `python3 agent.py`، وللتشغيل التلقائي استخدم launchd/LaunchAgent.

---

## زر «تشغيل» (Wake-on-LAN) — اقرأ هذا

الجهاز **المُطفأ لا يستطيع استقبال أي أمر** عبر الإنترنت (لأنه نائم فعلاً). التشغيل عن بُعد يحتاج **Wake-on-LAN**:

1. فعّل **WoL** من BIOS/UEFI ومن إعدادات كرت الشبكة في ويندوز (Allow this device to wake the computer).
2. إشارة الإيقاظ لازم تنطلق من **داخل شبكتك المحلية** — السحابة (Vercel) ما تقدر توصل لشبكتك. لذلك زر «تشغيل» يفيد في حالة:
   - عندك **جهاز ثاني دائم العمل** على نفس الشبكة (راوتر يدعم WoL، راسبيري باي، أو جهاز آخر) تشغّل عليه نفس الـ Agent، فيستقبل أمر `wake` ويرسل الإشارة للجهاز الرئيسي.
   - أو تستخدم تطبيق WoL على جوالك وأنت في نفس شبكة الواي فاي.
3. ضع عنوان MAC لكرت شبكة الجهاز الرئيسي في `wol_mac`.

> باقي الأوامر (إيقاف/سكون/قفل…) تعمل دائماً ما دام الجهاز شغّالاً والـ Agent يعمل.

## ملاحظات سريعة

- **السكون على ويندوز**: إن كان الإسبات (Hibernate) مفعّلاً قد ينام إسباتاً بدل Sleep. لإيقافه (كمسؤول): `powercfg -h off`.
- **لينكس**: أوامر `systemctl poweroff/reboot/suspend` قد تحتاج صلاحيات polkit (تعمل عادةً لمستخدم سطح المكتب).
- **الأمان**: استخدم كلمات سر قوية، ولا تشارك الرابط مع أحد. كل الاتصالات مشفّرة (HTTPS) عبر Vercel، والأوامر محصورة في قائمة ثابتة لا يمكن توسيعها من الجوال.
- **«إلغاء أمر الإيقاف»**: مفيد لو أرسلت Shutdown بخطأ مع تأخير — يلغيه قبل التنفيذ.

## استكشاف الأخطاء

| المشكلة | الحل |
|---------|------|
| الجوال يقول «غير متصل» | تأكد أن `agent.py` يعمل، وأن `server_url` و`agent_token` صحيحان. |
| خطأ `401` في سجل الـ Agent | قيمة `agent_token` لا تطابق `AGENT_TOKEN` في Vercel (أعد النشر بعد تعديله). |
| «كلمة السر خطأ» في الجوال | راجع `UI_PASSWORD` في Vercel وأعد النشر. |
| خطأ KV في الـ API | تأكد أنك أنشأت Vercel KV وربطته بالمشروع. |
